Exponential Distribution — Cloud Request Inter-arrival Time

Model the time between consecutive incoming requests using an Exponential Distribution.

Model Assumption:

This model assumes that cloud requests arrive according to a constant-rate Poisson arrival process. Therefore, the time between consecutive requests is modeled using an Exponential Distribution.

Important: Inter-arrival time is the time between arrivals. It is not the same as server response time or processing time.

Industry Problem

Suppose a cloud application receives requests at an average rate of 12 requests per minute.

We want to study how long we wait between consecutive incoming requests.

Input Parameters

Average number of requests arriving per minute.
Used for P(T ≤ t₁), P(T > t₁), and conditional probability.
Must satisfy t₂ ≥ t₁.

Exponential Distribution Formula

If T represents the inter-arrival time:

f(t) = λe−λt,   t ≥ 0
Mean = E(T) = 1 / λ
Variance = Var(T) = 1 / λ²
P(T ≤ t) = 1 − e−λt
P(T > t) = e−λt
P(T > t₂ | T > t₁) = e−λ(t₂ − t₁)   for t₂ ≥ t₁

Memoryless Property

The Exponential Distribution is called memoryless because the probability of waiting an additional amount of time does not depend on how long you have already waited.


For example, if no request has arrived for 3 seconds, the probability of waiting another 2 seconds is the same as it would have been at the beginning.


P(T > t₂ | T > t₁) = P(T > t₂ − t₁)
