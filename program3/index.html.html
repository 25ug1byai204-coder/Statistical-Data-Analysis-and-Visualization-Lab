Normal Distribution

Manufacturing Quality Control

🏭 Industry Problem

A manufacturing company produces metal components. The diameter of each component is expected to be close to a target value. Small variations are normal, but very large variations may indicate a quality problem.


The normal distribution can help engineers understand how the component measurements are distributed around the average value.

Input Parameters

Mathematical Formula

f(x) =
1 / (σ√(2π)) × e−(x−μ)² / 2σ²

The formula describes the probability density of a normally distributed variable.

Exponential Distribution

Cloud Request Inter-arrival Time

☁️ Industry Problem

A cloud application receives requests from users. The time between two consecutive requests can vary.


Cloud engineers can use the exponential distribution to model the waiting time between independent requests arriving at a system.

Input Parameters

Mathematical Formula

f(t) = λe−λt

P(T > t) = e−λt

The exponential distribution models waiting time between events.

Central Limit Theorem

Warehouse Processing Time

📦 Industry Problem

A warehouse processes many customer orders every day. The processing time of individual orders can vary depending on the order size, product location, and number of items.


Warehouse managers can use the Central Limit Theorem to understand the behavior of the average processing time for a sample of orders.

Input Parameters

Mathematical Formula

μx̄ = μ

σx̄ = σ / √n

As the sample size becomes larger, the distribution of sample means approaches a normal distribution.
